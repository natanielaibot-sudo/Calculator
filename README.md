# Calculator

A responsive calculator built with plain HTML, CSS and JavaScript. No libraries, no `eval()`.

## Features
- Add, subtract, multiply and divide
- Chained operations (2 + 3 + 4)
- Decimals, percent, delete and clear
- Division-by-zero handling
- Keyboard support (0-9, + - * /, Enter, Backspace, Esc)
- Automatic light and dark mode

## Run it
1. Download or clone this repository.
2. Open `index.html` in your browser.

## Tech
HTML5, CSS3 (grid, custom properties), vanilla JavaScript.

## What I learned
- Handling application state without a framework
- Avoiding floating point errors (0.1 + 0.2)
- Keyboard and accessibility support
